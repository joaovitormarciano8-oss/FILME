# Sistema de Cadastro de Filmes em C

Projeto desenvolvido durante a graduação em **Ciência da Computação** para praticar fundamentos da linguagem C e organização de código.

## Funcionalidades

- Cadastro de até 5 filmes
- Listagem dos filmes cadastrados
- Consulta dos dados de um filme
- Uso de memória dinâmica com `calloc`
- Liberação de memória com `free`

## Tecnologias

- C
- Struct
- Funções
- Arquivos `.h` e `.c`
- Alocação dinâmica de memória

## Estrutura

```text
.
├── main.c
├── funcoes.c
└── estruras.h
```

## Como executar

Com o GCC instalado:

```bash
gcc main.c funcoes.c -o filme
./filme
```

No Windows:

```bash
gcc main.c funcoes.c -o filme.exe
.ilme.exe
```

## Objetivo

Praticar programação estruturada, structs, funções e gerenciamento de memória em C.
